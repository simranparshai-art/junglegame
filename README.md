# Jungle Dash

A small 2D jungle game built with HTML5 canvas.

## How to play

1. Open [index.html](index.html) in a browser, or serve the folder with a local web server.
2. Move with WASD or arrow keys.
3. Collect fruits to reach 10 points before time runs out.
4. Avoid snakes and spiders.
5. Press R to restart.

## Files

- [index.html](index.html) — page shell
- [style.css](style.css) — visual styling
- [game.js](game.js) — game logic and rendering
